## 四、各角色职责与工作要求

### 组长（张月）
- 职责：统筹项目整体进度、制定总计划；负责 GitHub 仓库管理与分支合并；组织会议、协调各角色。
- 工作要求：
  1. 统筹教学周1-11全周期进度，制定总体计划并督促落实；
  2. 负责 GitHub 仓库管理（分支建立、合并、推送），并将仓库设置为开放模式（公开）便于老师查看；
  3. 组织组会、协调各角色，推动各项任务按时完成；
  4. 汇总各阶段报告（泛读报告、质量分析报告、设计方案文档），统筹最终成果演示 PPT 与答辩。

### 开发经理（黄梓涵、侍文博）
- 职责：组织代码精读与功能开发；负责代码质量、组织代码评审；解决技术难题。
- 工作要求：
  1. 教学周4：组织数据库与 model 分析，完成类图建模；熟悉 Django 架构；
  2. 教学周5-6：组织系统架构分析、建立架构模型，配合提交泛读报告；
  3. 教学周7-8：组织代码精读——协调6人分别选择不同 app（覆盖 blog、accounts、comments、djangoblog），利用工具做代码质量评估与优化，提交质量分析报告；
  4. 教学周9-10：牵头系统修改（至少完成一个功能点的修改或新增）及基本测试。

### 计划经理（刘雨婷）
- 职责：制定详细进度计划；跟踪任务完成情况；管理里程碑、提醒成员按时完成。
- 工作要求：
  1. 制定教学周1-11的详细周计划，明确每周交付物；
  2. 建立任务清单，跟踪各成员任务完成情况并定期更新；
  3. 管理关键里程碑（泛读报告、质量分析报告、功能修改、演示PPT）；
  4. 提前提醒成员各阶段截止时间，避免延误。

### 质量和过程经理（谢承志）
- 职责：制定代码/文档规范；组织评审；监督开发过程遵循规范。
- 工作要求：
  1. 制定代码标注规范与文档规范（注释格式、报告模板），保证全组统一；
  2. 组织各阶段报告评审（泛读报告、质量分析报告、设计方案文档），把控质量；
  3. 监督开发过程遵循规范（git 使用、分支管理、代码标注）；
  4. 配合代码质量评估，检查代码标注是否完整规范。

### 支持经理（朱亮宇）
- 职责：管理开发环境与工具；整理维护项目文档资料；提供技术支持。
- 工作要求：
  1. 维护开发环境（Python、Django、MySQL、git）配置说明，协助成员搭建与调试环境；
  2. 整理维护 doc/ 文件夹，管理各阶段报告文档的归档；
  3. 提供工具支持（代码质量评估工具、建模工具、TSPi 资料等）；
  4. 协助解决成员在环境、工具、GitHub 操作上的问题。
