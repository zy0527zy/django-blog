# 第四周组员任务分工与截图要求

> @所有人
>
> ⭐️ 每个人 👉 **熟悉总体架构 + 按角色做初步代码标注 + 截图**，另有【选做】角色产出。做完在群里回"**已push**"。
> 材料见 doc 下《DjangoBlog架构说明.md》《数据模型类图分析.md》《模板继承包含关系分析.md》《软件界面设计说明书.md》等。

## 一、通用要求

**第 1 件 · 熟悉总体架构**（搞懂总体架构，不是只懂自己那块）
- 打开 `doc/第四周/DjangoBlog架构说明.md`，弄懂 MVT 架构、src 目录结构、各 app 职责、URL 路由、一次请求怎么走。

**第 2 件 · 做初步代码标注 + 【选做】角色产出**
- 每人分到的 app 是按角色分配定的（具体完成步骤见私发）。
- 先读懂组长 push 的跟你板块对应的成果（见私发），再给源码加中文注释，commit + push 到自己分支。

**第 3 件 · 上传截图到钉钉文件夹**
- ① 代码注释 ② git push 输出 ③ 自己分支页 ④ 角色产出（选做），传到钉钉群个人文件夹。
- 统一 git 命令：

```bash
git fetch origin && git checkout 你的分支名 && git merge origin/master
# 加注释后：
git add 你改的文件
git commit -m "姓名 第四周代码标注 <app名>"
git push origin 你的分支名
```

**必须读懂了解的原因**：第四周"熟悉架构 + 代码标注"是在为第五周"系统架构分析 + 泛读报告"、第七八周"代码精读 + 质量评估"打底子，每人先吃透了自己 app，后面三周就能上手往后做。

> ⚠️ 注意：优先阅读群中任务再看私聊具体任务；选做任务统一 push 到 `doc/第四周/xxxxx-xxx.md`（例：`doc/第四周/任务跟踪表-刘雨婷.md`）。
