# 第四周组员任务分工与截图要求

> 发给各组员对照执行。每人 = **一个角色专属产出** + **一份个人代码标注**，结果 push 到自己分支，关键截图提交到**钉钉群"个人文件夹"**。
> 个人任务参考材料见同目录《DjangoBlog架构说明.md》。

## 一、共同要求（每个人都做）
1. 通读《DjangoBlog架构说明.md》，熟悉 Django MVT 架构；
2. 认领自己负责的 app，给代码添加中文注释（类说明、关键方法、关键逻辑）；
3. `git add` + `git commit` + `git push` 到自己的分支；
4. 按要求截图，提交到钉钉群个人文件夹。

## 三、每位成员需要提交的截图（提交到钉钉群个人文件夹）

1. **代码注释截图**：挑 2-3 处自己添加的注释，截图能看清代码和注释内容；
2. **git push 成功截图**：终端里 `git push` 的完整输出，能看到自己的分支名；
3. **分支页面截图**：GitHub 上自己分支的 commits 列表；
4. **角色产出截图**：把本周角色产出（计划表 / 规范 / 环境说明等）也截图提交。

## 四、截图注意事项
- 截图要清晰，不要糊；
- git 截图务必包含自己的**分支名**和 **commit 信息**，方便老师核对个人工作量；
- 提交位置：钉钉群 → 个人文件夹（按姓名命名）。
