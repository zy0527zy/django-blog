---

## 一、模板体系总览

DjangoBlog 的模板采用 **MVT 中 T（Template）层**的典型组织方式，按功能划分为多个"模板包"（目录），并通过 **继承（extends）**、**包含（include）**、**自定义标签（templatetags / inclusion_tag）** 三种机制复用页面结构。

```
src/templates/
├── share_layout/   # 共享布局包（全站页面的"骨架"）
├── blog/           # 博客页面包 + blog/tags 片段模板
├── account/        # 账号/认证页面包
├── comments/       # 评论片段模板包
├── oauth/          # 第三方登录页面包
├── search/         # 搜索页面包
└── plugins/        # 插件片段模板包（含 css/js 引用）
```

自定义标签库（位于各 app 的 `templatetags/`）：

```
src/blog/templatetags/blog_tags.py        # 博客核心标签/过滤器
src/blog/templatetags/vite_tags.py        # 前端资源(vite)加载标签
src/comments/templatetags/comments_tags.py# 评论标签
src/oauth/templatetags/oauth_tags.py      # OAuth 应用列表标签
```

## 二、继承关系（`{% extends %}`）

模板继承是页面复用布局的**主机制**。全站共有 **两个根布局模板**：

| 根模板 | 位置 | 用途 | 定义的 block |
|--------|------|------|--------------|
| `base.html` | `share_layout/base.html` | 全站主布局（导航+内容+侧栏+页脚） | `header`、`compress_css`、`content`、`sidebar`、`compress_js`、`footer` |
| `base_account.html` | `share_layout/base_account.html` | 账号/认证页面布局（独立的裸 HTML，不复用 base.html） | — |

**继承 `share_layout/base.html` 的页面：**

| 页面模板 | 所属包 |
|----------|--------|
| `blog/article_index.html`（首页） | blog |
| `blog/article_detail.html`（文章详情） | blog |
| `blog/article_archives.html`（归档） | blog |
| `blog/links_list.html`（友链） | blog |
| `blog/error_page.html`（错误页） | blog |
| `account/result.html`（操作结果） | account |
| `oauth/bindsuccess.html`（绑定成功） | oauth |
| `search/search.html`（搜索结果） | search |

**继承 `share_layout/base_account.html` 的页面：**

| 页面模板 | 所属包 |
|----------|--------|
| `account/login.html`（登录） | account |
| `account/registration_form.html`（注册） | account |
| `account/forget_password.html`（忘记密码） | account |
| `oauth/require_email.html`（绑定邮箱） | oauth |

## 三、包含关系（`{% include %}`）

包含关系用于在页面中**拼装可复用的小片段**，分为两类：

### 3.1 直接的 `{% include %}`

| 宿主模板 | 被包含的片段 |
|----------|--------------|
| `share_layout/base.html` | `share_layout/nav.html`、`share_layout/footer.html` |
| `share_layout/nav.html` | `share_layout/nav_node.html`、`share_layout/nav_node_mobile.html` |
| `blog/article_detail.html` | `comments/tags/comment_list_modern.html`、`comments/tags/post_comment_modern.html` |
| `comments/tags/comment_list.html` | `comments/tags/comment_item_tree.html` |

### 3.2 通过 `inclusion_tag` 渲染的片段（"模板与 tag 的关系"）

Django 的 `inclusion_tag` 机制把"数据准备逻辑"与"片段模板"绑定，标签被调用时自动渲染对应片段模板。这是本项目中**页面模板与片段模板之间最重要的隐式包含关系**：

| 标签库 | 标签（inclusion_tag） | 渲染的片段模板 |
|--------|----------------------|----------------|
| `blog_tags.py` | `load_breadcrumb` | `blog/tags/breadcrumb.html` |
| `blog_tags.py` | `load_articletags` | `blog/tags/article_tag_list.html` |
| `blog_tags.py` | `load_sidebar` | `blog/tags/sidebar.html` |
| `blog_tags.py` | `load_article_metas` | `blog/tags/article_meta_info.html` |
| `blog_tags.py` | `load_pagination_info` | `blog/tags/article_pagination.html` |
| `blog_tags.py` | `load_article_detail` | `blog/tags/article_info.html` |
| `blog_tags.py` | `load_article_detail_with_highlight` | `blog/tags/article_info_highlight.html` |
| `blog_tags.py` | （css/js 加载标签） | `plugins/css_includes.html`、`plugins/js_includes.html` |
| `comments_tags.py` | 评论列表标签 | `comments/tags/comment_list.html` 等 |
| `oauth_tags.py` | `load_oauth_applications` | `oauth/oauth_applications.html` |

## 四、模板与 tag 的加载关系（`{% load %}`）

页面模板通过 `{% load <标签库> %}` 声明对标签库的依赖，调用其中的标签/过滤器完成动态数据渲染：

| 标签库 | 来源 | 主要使用方 |
|--------|------|-----------|
| `blog_tags` | `blog/templatetags/blog_tags.py`（自定义） | blog 各页面（侧栏、面包屑、分页、文章卡片等） |
| `comments_tags` | `comments/templatetags/comments_tags.py`（自定义） | 文章详情页的评论区 |
| `oauth_tags` | `oauth/templatetags/oauth_tags.py`（自定义） | OAuth 应用列表页 |
| `vite_tags` | `blog/templatetags/vite_tags.py`（自定义） | base.html 前端资源加载 |
| `static` / `i18n` / `cache` / `compress` | Django 内置 | 各页面通用 |
