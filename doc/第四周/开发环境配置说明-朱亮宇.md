# DjangoBlog 开发环境配置说明

## 一、环境要求

Python 版本：3.13
数据库：MySQL 8.0 及以上

## 二、创建虚拟环境 .venv

在项目根目录打开终端，执行命令创建虚拟环境：

```bash
python -m venv .venv
```

激活虚拟环境：

- Windows cmd：

```bash
.venv\Scripts\activate
```

- Windows PowerShell：

```powershell
.venv\Scripts\Activate.ps1
```

- Linux / MacOS：

```bash
source .venv/bin/activate
```

激活成功后，命令行前缀会显示 `(.venv)`。

## 三、安装项目依赖包

保持虚拟环境激活，进入 src 目录执行：

```bash
pip install -r src/requirements.txt
```

等待依赖安装完成。

## 四、MySQL 数据库准备

启动本地 MySQL 服务，执行 SQL 创建项目数据库：

```sql
CREATE DATABASE django_blog DEFAULT CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
```

记下数据库名、账号、密码，用于后续配置。

## 五、.env 环境配置文件

在 src 目录新建 `.env` 文件，写入如下内容：

```ini
DB_NAME=django_blog
DB_USER=root
DB_PASSWORD=填写你的MySQL密码
DB_HOST=127.0.0.1
DB_PORT=3306
SECRET_KEY=填写Django密钥
```

> .env 文件保存敏感配置，不要提交到 git 仓库。

## 六、数据库迁移

```bash
cd src
python manage.py makemigrations
python manage.py migrate
```

## 七、启动项目

```bash
python manage.py runserver
```

访问 `http://127.0.0.1:8000`，即可进入博客系统。

### 附加命令：生成 Django 密钥

```bash
python -c "from django.core.management.utils import get_random_secret_key;print(get_random_secret_key())"
```

### .gitignore 配置

在项目根目录 `.gitignore` 添加下面内容，防止隐私文件上传：

```gitignore
src/.env
```
