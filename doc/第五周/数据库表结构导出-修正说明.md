# 数据库表结构导出-修正说明

> 修正对象：朱亮宇《数据库表结构导出-朱亮宇.md》
> 修正人：张月（组长） ｜ 修正日期：2026-10-08
> 结论：**24 张表数据本身完全正确**（字段、类型、主外键、索引逐表核对无误），仅做以下 3 处格式与命令修正，形成《数据库表结构导出（最终版）.md》。

## 修正点

| # | 位置 | 原文 | 修正为 | 原因 |
|---|---|---|---|---|
| 1 | 一、导出命令 | `mysql ... -e "SHOW CREATE TABLE blog_article\G"` | `-e "SHOW CREATE TABLE blog_article;"` | `\G` 只在 mysql 交互模式有效，放在 `-e` 里会报 `Unknown command '\G'`；并补充 `-h 127.0.0.1 -P 3306`，密码注明见 `.env` |
| 2 | 三、部分表 ENGINE 行 | 4 张 Django 表带 `AUTO_INCREMENT=N`，其余 20 张不带，不一致 | 统一去掉 `AUTO_INCREMENT=N` | `AUTO_INCREMENT` 是运行时自增计数器（随数据变化），不属于表结构，且原文档时有时无，统一去除更一致 |
| 3 | 三、Django 内置 8 张表顺序 | 乱序（django_migrations、django_session、django_site、auth_group_permissions、…） | 按第二节表清单顺序重排：auth_group、auth_group_permissions、auth_permission、django_admin_log、django_content_type、django_migrations、django_session、django_site | 与表清单顺序一致，便于核对 |
