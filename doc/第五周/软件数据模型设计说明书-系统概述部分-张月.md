## 1 软件系统概述

「栈外」是一款基于 Django 框架构建的个人技术博客系统，站名取意「栈里写码，栈外生活」，采用「技术 + 生活」双主题的内容定位，致力于解决个人知识沉淀与分享的需求。

### 1.1 系统定位

系统面向技术学习与生活记录两大场景，帮助博主以结构化的方式组织与发布内容：文章通过分类树（技术 → 后端开发 / 前端开发 / 数据库；生活 → 读书笔记 / 旅行）、标签、时间归档等多维结构进行管理，并提供全文搜索能力，使技术笔记与生活随笔都能被高效地沉淀、检索与分享。

系统基于 Django 5.2 的 MVT（Model-View-Template）架构实现，使用 MySQL 9.6 作为持久化存储，将文章、分类、标签、评论、用户、第三方授权等业务对象抽象为 24 张数据表。这些数据表及其之间的关联关系，正是本文档第 3 节数据模型设计的分析对象。

### 1.2 目标用户

| 用户类型 | 角色说明 |
|---|---|
| 博主（内容作者） | 系统的核心使用者，负责撰写、发布与管理文章，维护站点配置 |
| 访客（读者） | 浏览文章、按分类 / 标签 / 归档检索内容、发表评论与点赞的普通用户 |
| 站点管理员 | 通过 Django 管理后台统一管理文章、评论、分类、标签、用户与站点配置 |

### 1.3 核心价值

1. **内容沉淀与多维组织**：支持 Markdown 写作，通过分类树、标签、时间归档对文章进行多维组织，便于长期积累与回溯。
2. **高效的内容发现**：提供分类页、标签页、归档页、友链页与全文搜索等多类入口，读者可快速定位目标内容。
3. **互动与连接**：支持账号注册登录、第三方 OAuth 登录，以及评论、评论点赞、楼中楼回复，形成作者与读者之间的互动闭环。
4. **可扩展的插件体系**：通过插件机制（SEO 优化、阅读时长、图片懒加载、外部链接处理、版权声明等）在不改动核心代码的前提下按需扩展系统能力。
5. **便捷的运维管理**：内置 Django 管理后台，可对文章、评论、分类、标签、用户、站点配置进行统一管理。
