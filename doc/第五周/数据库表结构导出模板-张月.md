## 一、导出命令

```bash
# ① 列出 24 张表
mysql -u root -p djangoblog -e "SHOW TABLES;"

# ② 逐表查看结构（\G 竖排更好读）
mysql -u root -p djangoblog -e "SHOW CREATE TABLE blog_article\G"
```

（PowerShell 版：把 `mysql` 换成 `& "C:\Program Files\MySQL\MySQL Server 9.6\bin\mysql.exe"`）
