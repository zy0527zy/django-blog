# 第九、十周功能点现状与撞车提示清单

> 扫描人：张月（组长）｜扫描时间：2026-11-03
> 说明：逐 app 核对了现有 model / view / template，标出每个功能点是「真新增」还是「已存在/有雏形」，避免组员重复造轮子。**⚠️ = 有撞车，需调整做法或换方向**；**✅ = 真新增，可直接做**。

## 一、blog（黄梓涵）

### ⚠️ ① 文章阅读量统计 / 热门文章 —— 已存在，属「完善」
- `Article.views` 字段已存在（`blog/models.py`，`PositiveIntegerField(default=0)`）
- `Article.viewed()` 方法已存在（访问时浏览量 +1）
- 侧栏「热门文章」**已实现**（`blog/templatetags/blog_tags.py` 按 views 倒序 + `templates/blog/tags/sidebar.html`）
- 甚至有 `idx_status_views` 索引专门优化热门文章查询
- **建议改**：做「详情页阅读量展示优化」「本周/本月热门」「阅读量去重/防刷」等**增量改进**，别从零做阅读量统计。

### ⚠️ ② 文章置顶 —— 有雏形，属「完善」
- `Article.article_order` 字段已存在，Meta ordering `['-article_order', '-pub_time']`（order 越大越靠前 = 置顶逻辑）
- 模板 `article_info.html` / `article_info_highlight.html` 里 `{% if article.article_order > 0 %}` 已有置顶角标
- **建议改**：后台 admin 给 `article_order` 做「一键置顶/取消置顶」可视化操作，或新增 `is_top` 布尔字段 + 前端醒目样式，核心是**把已有 article_order 包装成好用的置顶功能**，别重复造排序字段。

## 二、accounts（侍文博）

### ✅ ① 用户头像上传 + 资料编辑 —— 真新增（头像/bio 缺，昵称已有）
- `BlogUser` 有 `nickname`，但**没有**本地 `avatar` 字段、也没有 `bio/简介` 字段
- 已有 `sync_user_avatar.py` 命令 + `save_user_avatar`（同步 OAuth 头像），**不是本地上传**
- **做法**：BlogUser 加 `avatar` 字段（上传 + 静态文件）+ `bio` 字段，补「个人资料编辑」前端页；昵称编辑复用已有 nickname。

### ✅ ② 修改密码 —— 真新增（缺「已登录改密码」页）
- 已有 `ForgetPasswordView`（忘记密码，邮箱验证码），但**没有「已登录状态下修改密码」的前端视图/表单**
- AbstractUser 自带 password，可做「个人中心-修改密码」（旧密码验证），与忘记密码区分开。

- **做法**：评论删除（作者删 / 管理员删）是真缺口；置顶评论需新增字段（如 `is_top`），都是真新增。

## 四、oauth（谢承志）

### ✅ ① 新增 Gitee 第三方登录 —— 真新增（无撞车）
- `OAuthConfig.TYPE` 只有 weibo/google/github/facebook/qq，**没有 gitee**
- `oauthmanager.py` 已有 `GitHubOauthManager` 可照抄
- **做法**：`TYPE` 加 `('gitee', 'Gitee')` + 新建 `GiteeOauthManager`（把 AUTH_URL/TOKEN_URL/API_URL 换成 Gitee 的，回调格式按 Gitee 文档）+ 模板加登录按钮。

### ⚠️ ② GitHub OAuth 修复 —— 先复现再改
- GitHub 实现已在 `oauthmanager.py` 的 `GitHubOauthManager`（授权/换 token/拉用户/邮箱/头像，逻辑完整）
- **建议**：先本地跑一遍 GitHub 登录，**定位具体 bug**（回调地址 / 代理 / 邮箱拉取失败等）再改，别凭空"修复"。
