# 第九、十周讲解视频要求

> 适用：全体成员（组长整合、组员出素材）
> 提交物：1 个 MP4 视频 → master 分支
> 依据：《第九、十周任务要求》——「本地运行优化后的 DjangoBlog 系统，录制视频讲解优化和新增的功能，视频开始时需要展示出小组编号和小组成员的姓名」。

---

## 一、总要求（打分点：规范性和质量）

| 项 | 要求 |
|---|---|
| 格式 | **MP4**，横屏 16:9，建议 1920×1080（1080p），音量清晰 |
| 开头 | **必须**先展示「小组编号 8」+「小组成员姓名」（张月、黄梓涵、侍文博、刘雨婷、谢承志、朱亮宇），可用一页 PPT/文字停留 3-5 秒 |
| 内容 | 本地运行优化后的系统，逐功能讲解每个「优化/新增」功能点 |
| 时长 | 建议 5-10 分钟（6 个功能点，每个约 1 分钟） |
| 语言 | 普通话，声音清楚，边演示边讲 |

---

## 二、视频结构（组长整合时按此顺序）

1. **开场**：小组编号 + 全员姓名页
2. **逐个功能讲解**（建议按 app 顺序）：
   - djangoblog：404/500 错误页、站点配置（张月）
   - blog：阅读量/热门文章、文章置顶（黄梓涵）
   - accounts：头像上传/资料编辑、改密码（侍文博）
   - comments：评论回复、删除/置顶（刘雨婷）
   - oauth：Gitee 登录、GitHub OAuth 修复（谢承志）
   - servermanager：统计面板、邮件优化（朱亮宇）
3. **收尾**：总结优化前后对比（可选）

> 每个功能讲解三要素：**① 谁做的 ② 改了/新增了什么（说清是「新增」还是「完善」）③ 运行效果演示（点开界面实际操作一遍）**。

---

## 三、组员素材要求（每人交，组长整合用）

| 项 | 要求 |
|---|---|
| 形式 | 录屏小段（推荐）或 3-5 张连续界面截图 + 文字说明 |
| 格式 | MP4（录屏）或 PNG（截图），横屏 |
| 时长 | 每人 30 秒 - 1 分钟 |
| 内容 | 只录**自己的功能点**，开头口播一句「我是 XX，我做的功能是 XX，属于新增/完善」 |
| 命名 | `姓名-功能点.mp4`（如 `黄梓涵-文章置顶.mp4`） |
| 提交 | 11-12 前，push 到自己分支（放 `doc/第九十周/演示素材/`）或传钉钉「第九十周/素材」文件夹 |

---

## 四、录制工具（任选）

- **Windows 自带**：`Win + G` 呼出 Xbox Game Bar 录屏
- **OBS Studio**（免费，画质好）
- **剪映**（录制 + 简单剪辑 + 加字幕/片头片尾）
- 录屏时建议关掉无关弹窗、用无痕窗口跑 DjangoBlog，保持画面干净。

---

## 五、注意事项

- 录制前先 `git pull` 最新代码，**在完整合并后的 develop 上录**，确保所有功能都跑得通；
- 演示功能时把关键路径点到位（如后台配置项、前端展示位置），别一闪而过；
- 视频命名：`第九十周讲解视频-第8组.mp4`，与报告、源码一起提交 master；
- 若个别功能演示需要登录/第三方授权（如 Gitee 登录），提前备好测试账号，避免录制时卡住。
