## 3. 人工分析代码的质量情况

### 3.1 代码风格

账户应用整体采用 Django 常见的模块划分方式：模型、表单、视图、认证后端、工具函数、管理后台和 URL 路由各自放在独立文件中。主要业务函数和类具有说明性文档字符串；本次精读在业务模块、类和方法以及关键校验逻辑处补充了 `#swb:` 注释，说明代码职责和关键设计原因。

代码风格方面发现并处理了未使用导入、通配符导入、未使用变量、导入顺序、行续接缩进和多余空行等问题。Flake8 会对 `#swb:` 报告 E265（井号后未留空格），这是课程要求的标识格式所致，属于预期项；项目组的分析材料也将此项定义为不计入代码风格缺陷。

### 3.2 代码设计

**优点：**

- **职责分离清楚：** `forms.py` 负责输入和业务校验，`views.py` 组织请求流程，`utils.py` 管理验证码发送与缓存，`user_login_backend.py` 单独扩展认证方式。
- **复用 Django 能力：** `BlogUser` 继承 `AbstractUser`；登录、注册和密码策略复用 Django 表单及密码验证器；认证后端用 `check_password()` 校验哈希密码。
- **请求跳转有安全校验：** `LoginView.get_success_url()` 使用 `url_has_allowed_host_and_scheme()` 检查登录后的跳转地址，降低开放重定向风险。
- **邮箱激活有签名校验：** 注册账户初始为未激活状态，验证链接携带基于站点密钥和用户 ID 生成的签名；视图重新计算签名后才启用账户。
- **验证码有效期集中管理：** `utils.py` 统一设置五分钟缓存有效期，发送、读取和校验操作由同一工具模块提供。

**仍可改进之处：**

- `ForgetPasswordForm.clean_email()` 对不存在的邮箱返回明确的“邮箱不存在”错误，攻击者可据此枚举已注册邮箱。可评估改用统一提示，同时兼顾用户体验和账户隐私。
- `EmailOrUsernameModelBackend.authenticate()` 直接执行 `'@' in username`。若认证调用未提供用户名而传入 `None`，会产生类型错误；可以先处理空值并明确返回认证失败。
- `ForgetPasswordView.form_valid()` 直接给 `password` 字段赋 `make_password()` 结果。使用模型的 `set_password()` 更符合 Django 用户模型接口，也更易维护密码更新逻辑。

### 3.3 编程技能

- **自定义认证后端：** `EmailOrUsernameModelBackend` 根据输入是否包含 `@` 选择邮箱或用户名字段，再调用用户模型密码校验方法，扩展登录标识而不改变 Django 的认证接口。
- **基于类的视图与表单校验：** 注册、登录和密码找回视图复用 Django 表单校验流程；表单通过 `clean_email()`、`clean_new_password2()` 和 `clean_code()` 分层验证数据。
- **签名令牌校验：** 注册激活链接由账户 ID 和站点密钥派生签名，激活端重新计算并比较，避免只依赖可被用户修改的普通状态参数。
- **缓存及过期策略：** 验证码写入 Django cache 并设置统一过期时间，使验证码处理与邮件发送逻辑解耦。
- **安全跳转控制：** 登录流程校验目标主机，仅允许安全的站内跳转。

## 6. 下一步改进计划

| 优先级 | 改进点 | 现状 / 不足 | 改进方案 |
|:---:|---|---|---|
| 高 | 降低密码找回过程中的邮箱枚举风险 | 表单错误提示会透露邮箱是否注册 | 评估统一响应文案，并确保未注册邮箱不能进入密码更新流程 |
| 中 | 处理认证用户名为空的边界 | 后端对 `None` 执行 `in` 判断会报错 | 在判断邮箱或用户名之前处理空值，并通过边界场景验证认证失败行为 |
| 中 | 使用 Django 用户模型密码接口 | 视图直接赋值 `make_password()` 结果 | 改为 `set_password()` 后保存，减少对密码字段实现细节的依赖 |
| 中 | 增强关键账户流程的自动化覆盖 | 现有检查以静态分析和人工精读为主 | 为邮箱枚举策略、空用户名认证、激活签名不匹配和密码重置增加针对性测试 |
| 低 | 保持静态检查结果稳定 | `#swb:` 格式产生预期的 E265 提示 | 在质量记录中持续注明 E265 为任务格式导致的预期项；每次修改后运行 `ruff check src/accounts` 和 `flake8 src/accounts` |
