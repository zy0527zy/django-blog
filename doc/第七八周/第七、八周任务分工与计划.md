## 七、Git 与协作约定

- **分支**：`姓名首字母_branch`，push 到自己分支（不 push develop / master）。
- **commit 命名**：
  - 代码注释 → `姓名 第七八周代码标注 <app>`
  - 报告/工具分析 → `姓名 第七八周质量分析 <app>`
- **文件命名**：
  - 质量分析报告板块 → `开源软件质量分析报告-<部分>-<姓名>.md`
  - 编码规范 → `编码规范-谢承志.md`
  - 评审意见 → `第七八周代码评审-<姓名>.md`（谢承志为 `第七八周质量过程评审-谢承志.md`）
- **注释标识**：`#姓名缩写:`（zy / hzh / swb / lyt / xcz / zly），每人唯一，便于区分谁标注了哪行。
- **合并规则**：张月审核（走 PR）通过后合入 develop；develop 定稿后张月合并到 master。
- **图片**：质量分析截图 / 报告配图导出成 PNG，放 `doc/第七八周/imgs/`，文件名用英文（如 `blog-sonar-hzh.png`），md 里用相对路径 `![](imgs/xxx.png)`，与 md 一起 add/commit/push。
