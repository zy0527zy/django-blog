# 待分析开源软件概述（第 1 节）

> 负责人：张月（组长）。本板块为《开源软件质量分析报告》第 1 节草稿，统计数字可与朱亮宇核对后定稿。

## 1. 软件名称

**DjangoBlog**——一个开源的 Django 博客系统。本组以该项目为分析对象，部署实例主题命名为「栈外」（副标题「栈里写码，栈外生活」）。

## 2. 主要功能

- **博客内容**：文章发布 / 编辑 / 删除，分类、标签、归档、友链、侧边栏；
- **检索与订阅**：全文搜索（Whoosh / Elasticsearch 双后端，支持中文分词）、RSS 订阅、站点地图（sitemap.xml）；
- **内容交互**：Markdown 编辑、评论与点赞（支持楼中楼回复）、第三方 OAuth 登录（GitHub 等）；
- **运维与扩展**：后台管理、服务器管理（运维命令 / 邮件日志）、运行时插件系统（版权声明、阅读时长、外链处理、浏览量、SEO、图片懒加载、文章推荐、CDN 缓存清理等 8 个插件）。

## 3. 编程语言与框架

Python（Web 框架 Django），前端 Vue + Vite；配套 MySQL 数据库、缓存（LocMem / Redis 可选）、全文检索（Whoosh / Elasticsearch 可选）。

## 4. 代码整体情况

- Python 源文件：**152 个**（.py）
- 代码总行数：约 **16013 行**
- 类（class）数量：**268 个**
- 主要包：**6 个业务 app**（blog、accounts、comments、oauth、servermanager、djangoblog）+ **1 个插件目录**（plugins），共 **7 个主要代码包**；djangoblog 下含 `plugin_manage` 子包（插件基类、钩子、加载器）。

> 注：以上统计基于 src/ 目录（代码根目录），由脚本统计得到；朱亮宇复核后以最终口径为准。
